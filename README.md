# PathLinks Clinical Decision Support (V2.0)

A comprehensive clinical decision support tool for UK General Practice, designed to streamline blood test actioning and integrated with EMIS Web.

## 🚀 Key Features

- **Protocol-Driven Actioning**: Over 50 standard blood tests with NICE-aligned clinical guidance.
- **Diabetes Management**: Automated interpretation of HbA1c (Prediabetes, T2DM diagnosis, and intensification triggers).
- **Lipid & CVD Risk**: Integrated **QRISK3 Calculator** that can simulate EMIS data imports.
- **Antenatal & Viral Screening**: Safe interpreting of HIV, Syphilis, Hep B, and Varicella (Chickenpox) in pregnancy.
- **Immunology & Allergy**: Grade-based interpretation of Specific IgE (RAST) and post-vaccination immunity checks (Anti-HBs).
- **Tumour Markers**: Age-specific PSA thresholds and NICE 2WW referral prompts for CA125, CA19-9, etc.
- **EMIS Integration**: Downloadable XML protocols for automated clinical alerts within EMIS Web.
- **Learning Topics**: Searchable clinical knowledge extracted from USB podcast MP3s (transcripts); read full text in-app.
- **Decision Tools**: ~900 clinical decision tools by system with **NICE-based management** (drug choices, targets, referral criteria); dropdowns give concrete guidance from guidelines, not generic “see NICE”.

## 📁 Project Structure

- `/app`: The core web application (index.html, style.css, script.js).
- `/data`: The clinical engine (`blood_tests_protocol.json`), `knowledge_base.json` (transcripts), and `decision_tools_protocol.json` (~900 tools with NICE-based management steps; generated by `build-decision-tools.js`).
- `/scripts`: `parse-mp3-topics.js`, `transcribe_mp3_to_knowledge.py`, `anonymize_transcripts.py`, **`build-decision-tools.js`** (learning library + NICE → decision_tools_protocol.json).
- `/emis_templates`: EMIS Web compatible XML protocols.
- `/docs`: EMIS setup guide, clinical protocol, **Knowledge extraction**, and **FORENSIC_AUDIT.md** (repo/deploy audit).

**Deploy:** Vercel serves from the **repo root** (root `index.html` and `data/`). Run `scripts/anonymize_transcripts.py` before deploying so the live site uses anonymized transcripts. See `docs/FORENSIC_AUDIT.md` for a full deploy checklist.

## 🛠️ How to Use

1. **Dashboard**: Open `http://localhost:3000` to access the clinical analysis tool.
2. **Actioning**: Select a category and parameter, enter the value, and follow the clinical checklist.
3. **Protocols**: Browse all tests and click **View Guidance** for full protocol text.
4. **Learning topics**: Search and read transcript text from the USB podcast library (if `knowledge_base.json` is present).
5. **EMIS Workflow**: Go to the "EMIS Integration" tab to download the latest protocol file for import into your clinical system.

### Extracting knowledge from USB MP3s

With the USB drive connected (e.g. at `/Volumes/NO NAME`):

1. **Parse filenames**: `node scripts/parse-mp3-topics.js "/Volumes/NO NAME"`
2. **Transcribe** (requires [ffmpeg](https://ffmpeg.org) and Python):  
   `python -m venv .venv && .venv/bin/pip install -r requirements.txt`  
   then  
   `.venv/bin/python scripts/transcribe_mp3_to_knowledge.py "/Volumes/NO NAME"`  
   Use `--limit 5` to test; omit for full run. See **docs/KNOWLEDGE_EXTRACTION.md** for details.

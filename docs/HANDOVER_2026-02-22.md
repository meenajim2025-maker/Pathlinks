# Handover for next agent
**Date:** 22 February 2026

## Summary of recent work

### 1. Drug interactions (new section)
- **New nav item and view:** "Drug interactions" between Calculators and Education Sandbox.
- **Data:** `app/data/drug_interactions.json` – BNF/BNFc-style interaction pairs with severity (contraindicated, major, moderate, minor), optional `source` (e.g. "BNF"), and `formularyRefs` (BNF, BNFc, Stockley's, Lexicomp).
- **Logic:** `app/main.js` – fetches JSON, parses drug list (newline/comma/semicolon, normalises doses), expands class aliases (e.g. ramipril → "ace inhibitor", ibuprofen → "nsaid"), matches interactions, groups results by severity, shows disclaimer and sources.
- **UI:** Paste/type drug list → "Check interactions" → results grouped by severity with "Verify in current BNF/BNFc" disclaimer. Styling in `app/style.css` (`.drug-interactions-list`, `.drug-interaction`, severity colours, `.drug-interactions-disclaimer`, `.drug-interactions-sources`).

### 2. Triage – specific pathways (yes/no algorithms)
Generic "GP Triage – disposition" was replaced/refined with **topic-specific pathways** so triage staff see **short synopses** for each disposition (what counts as 999, same-day, etc.), not a generic list.

- **Build script:** `scripts/build-decision-tools.js` – generic triage fallback is now a **4-step yes/no** flow (Emergency? Same day? 24–48 h? Self-care?). When a **topic-specific** template matches, that pathway is used instead.
- **Template matching:** `scripts/management-content.json` – new **matchAll** option: if `matchAll: true`, **all** keywords must match the tool title (so only "Triage – wound – severe" gets wound pathway, not every triage tool). `getManagementSteps` / `getManagementEvidence` in `build-decision-tools.js` support `tmpl.matchAll`.

**Pathways added (all in `scripts/management-content.json`, order matters – specific before generic):**

| Pathway | Keywords (matchAll) | Evidence |
|--------|---------------------|----------|
| Triage – wound – severe | triage, wound, severe | NICE CKS, Local formulary, NICE NG51, Urgent care |
| Triage – head injury | triage, head injury | NICE CG176, CKS, Urgent care |
| Triage – collapse / unconscious | triage, collapse, unconscious | NICE CKS Collapse/Syncope, NG51, Local formulary, Urgent care |
| Triage – mental health – crisis | triage, mental health, crisis | NICE CKS Mental health, NG10, NG51, Urgent care |

Each pathway has 4–5 steps with **Yes** (disposition + short synopsis) and **No** (proceed to next question). Mental health crisis pathway is **crisis-specific** (999: suicide/self-harm/overdose/risk to others/psychosis; same-day: crisis team referral; etc.) – not the generic "collapse, chest pain, stroke" list.

### 3. After changing management-content or triage pathways
1. Run: `node scripts/build-decision-tools.js`
2. Optionally bump protocol cache in `app/main.js` (e.g. `?v=11`) so clients load new protocol.

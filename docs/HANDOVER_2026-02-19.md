# AI Handover Guide: PathLinks Clinical (Feb 19, 2026)

## 📌 Project Overview
PathLinks is a premium Clinical Decision Support (CDS) tool for primary care, integrating guidline-backed management (NICE CKS, PCDS) with standalone clinical calculators and EMIS Web integration templates.

## 🛠 Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, and JavaScript (ES6+).
- **Styling**: Premium custom CSS (Glassmorphism, CSS Variables, Responsive Grids).
- **Deployment**: Vercel (Production URL: `https://pathlinks-clinical.vercel.app`).
- **Data Build**: Node.js scripts for processing clinical content.

## 🗄 Data Architecture
The project uses a structured data pipeline to generate the decision tools:

1.  **`scripts/management-content.json`**: The source of truth for management steps.
    *   **Keyword System**: Uses a "First Match Wins" regex system. 
    *   **Structure**: Each template has `keywords` and `steps`. Steps are usually `dropdown` or `checklist` types.
    *   **Priority**: More specific keywords (e.g., "scalp") should be placed **above** broader keywords (e.g., "psoriasis") to ensure correct template selection.
2.  **`scripts/build-decision-tools.js`**: The build engine.
    *   It maps topics from `scripts/extra-tools-bulk.json` to the templates in `management-content.json`.
    *   **Fallbacks**: It contains logic to provide "Smart Fallbacks" for assessment, management, and referral if no specific template is found. (Dermatology has a custom fallback to avoid generic MSK advice).
3.  **`data/decision_tools_protocol.json`**: The published artifact used by the app.
    *   Generated by running: `node scripts/build-decision-tools.js`.

## 🚀 Key Modules
### 1. Decision Tools
- **Search Logic**: Supports global search and system-specific filtering.
- **Priority Logic**: Prioritizes "Specific Pathways" over "Generic Fallbacks" in the search results UI (`script.js`).

### 2. Calculators (`calculators-view`)
- **NEWS2 / qSOFA**: Combined acute sickness scores.
- **QRISK3**: Cardiovascular risk assessment.
- **Wells Score (DVT)** & **CURB-65**: Validated clinical scores.
- **Integration**: QRISK3 supports internal links from the dashboard.

### 3. EMIS Integration
- Found in `emis_templates/`.
- `pathlinks_v2.xml`: The primary EMIS protocol template for lab result actioning.

## 🏗 Maintenance Workflow
To update clinical content:
1.  Edit `scripts/management-content.json`.
2.  Run build: `node scripts/build-decision-tools.js`.
3.  Sync with app: `cp data/decision_tools_protocol.json app/data/decision_tools_protocol.json`.
4.  Deploy: `npx vercel --prod`.
